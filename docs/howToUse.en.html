Technology
Node.js + API
Meoo Bot is written in Node.js and uses an API to communicate with the Rubika platform.

This architecture allows the bot to send requests to Rubika and handle user messages and interactions.
How to Play
Start Playing 🎮
To get started, simply START the bot.
You can then play different games and collect points.
  • Lucky Game
  • Tic-Tac-Toe
  • More entertainment games
  • Compete with other users and earn more points
The more points you collect, the higher you can climb on the Scoreboard and compete for the top positions. 🏆

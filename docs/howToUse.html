میو بات یک ربات سرگرمی و امتیازی است که با بازی‌های مختلف به شما امکان جمع‌آوری امتیاز و رقابت با دیگر کاربران را می‌دهد.

Node.js + API
میو بات با استفاده از Node.js نوشته شده است و برای ارتباط با پلتفرم روبیکا، از API استفاده می‌کند.

این ساختار باعث می‌شود ربات بتواند درخواست‌های لازم را به سرویس روبیکا ارسال کرده و پیام‌ها و تعاملات کاربران را مدیریت کند.

شروع بازی 🎮
برای شروع کافی است ربات را START کنید.
سپس می‌توانید با انجام بازی‌های مختلف امتیاز جمع کنید.
  • بازی شانسی
  • بازی دوز
  • بازی‌های سرگرمی دیگر
  • رقابت با دیگر کاربران و افزایش امتیاز
با جمع‌آوری امتیاز بیشتر می‌توانید در Scoreboard صعود کنید و جایگاه بهتری در جدول امتیازات داشته باشید. 🏆
